Suas corridas, conectadas.

A conexão com o Strava está implementada, mas precisa das credenciais da sua aplicação antes da primeira autorização. Os registros manuais funcionam enquanto isso.

1. Cadastrar a aplicação Strava

  1. Abra Strava API Settings. A documentação atual exige assinatura Strava para cadastrar uma aplicação. O acesso inicial é limitado ao próprio atleta.
  2. Informe nome: Prumo; website: https://evoluir-hazel.vercel.app; Authorization Callback Domain: evoluir-hazel.vercel.app.
  3. O endereço completo de retorno usado pelo aplicativo é https://evoluir-hazel.vercel.app/api/strava?op=callback.

2. Ativar na Vercel

Nas configurações do projeto evoluir → Environment Variables → Production, cadastre:

  • APP_ORIGIN: https://evoluir-hazel.vercel.app.
  • STRAVA_CLIENT_ID e STRAVA_CLIENT_SECRET: os valores privados fornecidos pelo Strava.
  • STRAVA_SESSION_SECRET: um segredo aleatório de pelo menos 32 caracteres, criado pelo gerador do seu gerenciador de senhas.

Marque os segredos como sensíveis. Faça um novo deploy para aplicar as variáveis. Abra Corrida no Prumo, leia o consentimento e toque em Conectar minha conta Strava.

Cadastre as credenciais diretamente na Vercel. Não as envie em chat, não use prefixo VITE_ e não coloque valores reais no código ou no GitHub.

3. Se você corre com Nike Run Club

No NRC, abra Perfil → Configurações → Parceiros → Strava e autorize. Essa conexão envia as novas corridas; não transfere o histórico anterior. Depois de uma corrida sincronizada, abra Corrida no Prumo: as atividades serão consultadas automaticamente.

As atividades do Strava são uma consulta privada temporária. Não entram nos backups nem atualizam as metas de registros manuais.

Atalho no iPhone: ideia para uma próxima etapa

O Tocar Atrás aceita dois ou três toques. Você pode atribuir um atalho em Ajustes → Acessibilidade → Toque → Tocar Atrás. Use um atalho que abra o app de corrida; iniciar a gravação depende das ações oferecidas pelo NRC ou Strava no seu aparelho.

O Prumo ainda não mede distância por GPS e não registra corridas em segundo plano. Grave no aplicativo de corrida e consulte depois. Não calculamos quilômetros apenas com um cronômetro.
